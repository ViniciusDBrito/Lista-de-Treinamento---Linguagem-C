# Lista-de-Treinamento---Linguagem-C

Este repositório reúne uma coleção de exercícios desenvolvidos na linguagem C, com foco no treinamento de lógica de programação e no fortalecimento dos fundamentos da linguagem.

O objetivo principal é praticar a resolução de problemas e aprimorar a organização e estruturação do código.

Os exercícios estão organizados em arquivos separados, cada um contendo um problema específico para prática.
O código é comentado para facilitar o entendimento da lógica utilizada.

Realizada em 16/04/2024, vinculado a graduação em Análise e Desenvolvimento de Sistemas - Araraquara
